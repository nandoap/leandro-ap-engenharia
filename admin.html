Configure as credenciais públicas do Supabase No código, localize: ```javascript const SUPABASE_URL = "COLE_A_PROJECT_URL_AQUI"; const SUPABASE_ANON_KEY = "COLE_A_CHAVE_PUBLICA_ANON_OU_PUBLISHABLE_AQUI"; ``` Substitua pelos valores do seu projeto, encontrados em **Supabase → Project Settings → API** ou **Connect**. Use somente a **chave pública `publishable` ou `anon`**. Não use `service_role`, `sb_secret` nem a senha do banco. As chaves públicas podem estar visíveis no código de um site estático; a proteção dos registros depende das políticas RLS que você já configurou. ## 3. Configure o armazenamento privado das fotos O cadastro de clientes e inspeções funciona sem armazenamento de fotos. Para ativar as fotos, crie um bucket privado chamado `laudos-fotos` e execute este SQL no Supabase. Ele cria as regras para cada usuário acessar somente arquivos dentro da própria pasta: ```sql insert into storage.buckets (id, name, public, file_size_limit, allowed_mime_types) values ( 'laudos-fotos', 'laudos-fotos', false, 10485760, array['image/jpeg', 'image/png', 'image/webp', 'image/gif'] ) on conflict (id) do update set public = false, file_size_limit = 10485760, allowed_mime_types = array['image/jpeg', 'image/png', 'image/webp', 'image/gif']; drop policy if exists "laudos_fotos_select_own" on storage.objects; drop policy if exists "laudos_fotos_insert_own" on storage.objects; drop policy if exists "laudos_fotos_update_own" on storage.objects; drop policy if exists "laudos_fotos_delete_own" on storage.objects; create policy "laudos_fotos_select_own" on storage.objects for select to authenticated using ( bucket_id = 'laudos-fotos' and (storage.foldername(name))[1] = (select auth.uid()::text) ); create policy "laudos_fotos_insert_own" on storage.objects for insert to authenticated with check ( bucket_id = 'laudos-fotos' and (storage.foldername(name))[1] = (select auth.uid()::text) ); create policy "laudos_fotos_update_own" on storage.objects for update to authenticated using ( bucket_id = 'laudos-fotos' and (storage.foldername(name))[1] = (select auth.uid()::text) ) with check ( bucket_id = 'laudos-fotos' and (storage.foldername(name))[1] = (select auth.uid()::text) ); create policy "laudos_fotos_delete_own" on storage.objects for delete to authenticated using ( bucket_id = 'laudos-fotos' and (storage.foldername(name))[1] = (select auth.uid()::text) ); ```
